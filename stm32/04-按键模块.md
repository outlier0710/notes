# 04 · 按键模块（输入的第一课）🔘

> 日期：2026-11-08 ｜ 板子：STM32F103C8T6 最小系统板（按键接 PB1 / PB11）｜ IDE：Keil MDK5

## 一、实验目标

读懂并跑通 Key.c 驱动模块：两个按键 → 返回键号（1/2/0）→ main 里决定干什么（翻转灯、换模式）。这是第一个"**输入驱动输出**"的完整闭环。

## 二、完整代码（含逐行注释）

```c
#include "stm32f10x.h"    // 设备头文件
#include "Delay.h"        // 延时模块（消抖要用，所以必须 include）

/* ============ 初始化：把 PB1、PB11 配成"输入脚" ============ */
void Key_Init(void)
{
    // ① 开时钟：给 GPIOB 通电（铁律）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

    // ② 配置单：这次关键是"模式"
    GPIO_InitTypeDef GPIO_InitStucture;
    GPIO_InitStucture.GPIO_Mode  = GPIO_Mode_IPU;              // 上拉输入（见概念1）
    GPIO_InitStucture.GPIO_Pin   = GPIO_Pin_1 | GPIO_Pin_11;   // 同时选中 PB1 和 PB11
    GPIO_InitStucture.GPIO_Speed = GPIO_Speed_50MHz;           // 输入模式下无实际作用，习惯性填上

    // ③ 交表
    GPIO_Init(GPIOB, &GPIO_InitStucture);
}

/* ============ 按键扫描：返回"哪个键被按了"，没按返回 0 ============ */
uint8_t Key_GetNum(void)
{
    uint8_t KeyNum = 0;    // 默认"没按键"

    // ---- 检查 1 号键（PB1）----
    if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)   // ==0 表示按下
    {
        Delay_ms(20);    // 按下消抖

        while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0);
        // 空循环死等：按住期间程序卡在这里，松手才往下走

        Delay_ms(20);    // 松手消抖

        KeyNum = 1;      // 记录：1 号键被按了一次
    }

    // ---- 检查 11 号键（PB11），逻辑相同 ----
    if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0)
    {
        Delay_ms(20);
        while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0);
        Delay_ms(20);
        KeyNum = 2;
    }

    return KeyNum;    // 交还结果：0=没按，1=键1，2=键2
}
```

## 三、四个必懂概念

1. **IPU 上拉输入**：按键一端接引脚一端接 GND。松手时引脚悬空，上拉电阻给它默认接"弱高电平"→ 松手 = 1，按下 = 0。这就是 `==0` 判断按下的原因。输入模式四兄弟：IPU 上拉 / PD 下拉 / IN 浮空 / AIN 模拟。

2. **消抖（Delay 20ms）**：按键金属片碰撞会"哆嗦"几毫秒，不消抖一次按键可能被读成多次。按下后等 20ms 再判断、松手后再等 20ms。

3. **`while(...);` 死等松手**：好处是按住 3 秒也只算一次；代价是**按住期间整个程序卡住**（流水灯会停）。这正是第 3 周"外部中断"要解决的问题。

4. **返回键号的 API 设计**：`Key_GetNum` 只报告"发生了什么"，由 main 决定干什么——驱动模块管操作、main 管决策，这是模块化编程的精髓。
