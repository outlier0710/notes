# 02 · 流水灯与蜂鸣器 💡🔊

> 日期：2026-11-08 ｜ 板子：STM32F103C8T6 最小系统板 ｜ 下载器：ST-Link ｜ IDE：Keil MDK5

## 一、实验目标

1. **流水灯**：让一组 LED 依次点亮，形成"流动"效果
2. **蜂鸣器**：用 GPIO 控制蜂鸣器发声 / 静音

## 二、关键代码

### 流水灯（核心思路：依次点亮 + 延时）

```c
int main(void)
{
    // 时钟与 GPIOA 初始化同 01 篇（开时钟 → 填结构体 → GPIO_Init）
    while (1)
    {
        GPIO_Write(GPIOA, ~0x0001);   // 第 1 个灯亮
        Delay_ms(500);
        GPIO_Write(GPIOA, ~0x0002);   // 第 2 个灯亮
        Delay_ms(500);
        // …… 依次类推，也可以用移位写成循环版
    }
}
```

江协的循环写法（配合变量 i）：

```c
while (1)
{
    GPIO_Write(GPIOA, ~(0x0001 << i));   // i 从 0 到 7 循环
    Delay_ms(500);
    i++;
    if (i >= 8) i = 0;
}
```

### 蜂鸣器

```c
GPIO_ResetBits(GPIOB, GPIO_Pin_12);   // 响
GPIO_SetBits(GPIOB, GPIO_Pin_12);     // 停
```

**知识点：有源 vs 无源蜂鸣器**

- **有源**：内部自带振荡源，通电就响，GPIO 电平直接控制（江协用的这种）
- **无源**：需要给它 PWM 方波才能响 → 第 5 周学 PWM 时它就是现成练习对象

## 三、新学的知识点

1. **GPIO_Write(GPIOx, 值)**：一次写整个端口 16 位，比一个一个 ResetBits/SetBits 更高效
2. **取反的妙用**：LED 低电平点亮，"第 i 位亮、其他灭"就写 `~(0x0001 << i)` —— 移位 + 取反，位运算第一次在真实程序里上岗
3. **蜂鸣器的电流问题**：GPIO 引脚只能提供很小电流，实际要通过三极管放大——引脚负责"发令"，不负责"出力"
