# 05 · 光敏传感器与 OLED 🧭

> 日期：2026-11-08 ｜ 板子：STM32F103C8T6 最小系统板 ｜ IDE：Keil MDK5

## 一、实验目标

1. 读**光敏传感器模块**的 DO 数字输出（有光 / 无光 → 1 / 0）
2. 用江协提供的 **OLED 驱动模块**把结果显示在屏幕上

这是第一个"**传感器 → 屏幕**"的完整小系统。

## 二、关键代码

### 读光敏传感器（和按键一模一样的套路）

```c
// 初始化：上拉输入（DO 输出是数字电平，当按键读）
GPIO_InitStucture.GPIO_Mode = GPIO_Mode_IPU;
GPIO_InitStucture.GPIO_Pin  = GPIO_Pin_x;   // 按你实际接的引脚填

// 读取：比较结果，0 或 1
uint8_t Light = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_x);
```

### OLED 显示（黑盒用法）

```c
OLED_Init();                          // 初始化屏幕（上电调一次）
OLED_ShowString(1, 1, "Light:");      // 第1行第1列显示字符串
OLED_ShowNum(2, 1, Light, 1);         // 第2行显示数字，最后参数是位数
```

## 三、新知识点

1. **传感器模块的三根线**：VCC / GND / DO（有的还有 AO）。
   - **DO** = 比较结果，数字 0/1 —— 今天用的就是这个，读法和按键完全一样
   - **AO** = 原始的模拟电压 —— 第 6 周学 ADC 时用它，能读出连续的光照强弱
2. **OLED 当调试窗口**：从今以后所有实验都可以把变量显示到屏幕上看。串口还没学之前，它就是你的"printf"。
3. **模块上的旋钮**：光敏模块有个可调电阻，决定"多暗算遮挡"的阈值——**硬件本身也在被配置**，这是"软硬协同"的第一个直观例子。

## 四、踩坑记录

- _1.忘记给函数初始化导致oled屏幕没有反应
- 2.判断外部数据也就是GPIO_ReadInputDataBit（）=1与控制蜂鸣器开关写反了导致程序变成在无感应到亮度变化就一直响

## 五、收获

1. 传感器读数和按键读数是同一个套路：配置输入 + 读电平
2. OLED 从此成为"万能观察窗"，后面 PWM、MPU6050 全要靠它显示
3. 认识到同一类硬件可以有"简单版"（DO）和"精细版"（AO）两种用法
