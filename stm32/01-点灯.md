# 01 · 点灯实验 💡

> 日期：2026-11-_5_ ｜ 板子：STM32F103C8T6 最小系统板 ｜ 下载器：ST-Link ｜ IDE：Keil MDK5

## 一、实验目标

让 PA0 引脚输出低电平，点亮板载 LED（板载灯为低电平点亮）。

## 二、关键代码

```c
// 第1步：开 GPIOC 时钟（电闸）
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

// 第2步：填配置单（结构体）
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;   // 推挽输出
GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_0;        // PA0
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

// 第3步：交表
GPIO_Init(GPIOA, &GPIO_InitStructure);

// 点灯：PA0 输出低电平
GPIO_ResetBits(GPIOA, GPIO_Pin_0);
```

## 三、原理（我的理解）

C 代码 → Keil 编译成机器码 → 烧进芯片 Flash → CPU 逐条执行 → 库函数最终写寄存器 → 引脚电平变化 → 灯亮。
全程发生在芯片内部，只有引脚电平跨越芯片边界。

## 四、踩坑记录：No target connected ⭐

**现象**：Keil 点 Load 报 `No target connected`，Debug Settings 里 SW Device 框空白。

**排查过程**（按顺序试了）：

1. 查驱动 —— 设备管理器能认到 ST-Link，电脑侧没问题
2. 逐根读板子排针丝印，核对 4 根线（3V3 / GND / SWCLK /SWDIO
4. 重新插拔、换短杜邦线
5. 确认 BOOT0 跳线在 0

## 五、收获

1. 点灯是单片机界的 Hello World，走通了"编译→下载→运行"的完整链路
