# 🚁 无人驾驶航空器系统工程 · 四年学习路线（考研版）

> 郑州航空工业管理学院 · 大一 · 制定于 2026-10-26
> 目标：2029 年 12 月初试，考取**厦门大学航空航天学院 085503 航空工程（专硕）**

## 一、总原则

1. **GPA 永远第一优先级** —— 没有保研名额，考研是唯一升学通道，**课内学扎实 = 提前备考**
2. **双线推进**：编程线（C → Python → STM32）＋ 动手线（开发板 → 无人机）
3. **英语每天 20 分钟，三年不断** —— 英语单科线是我最不能失守的关
4. **作品集从大一开始积累** —— 笔记、竞赛、项目 = 复试的弹药

## 七、📈 提高上岸概率的四个策略

1. **初试分数是唯一硬通货** —— 初试高 20 分，一切出身偏见都失效
2. **英语不偏科** —— 50 分单科线淘汰的就是总分够、英语瘸的人
3. **把「郑航」讲成优势** —— 航空特色院校 + 无人机专业 + 低空经济方向深造，专业匹配度碾压跨考生
4. **留梯度备选** —— 同赛道：南航、西工大（更难）／昌航、中航大（更稳），大三上根据模考实力最终锁定
