# 🚁 无人驾驶航空器系统工程 · 大一学年学习路线

> 双非大一 · 起始时间：2026 年 10 月 · 目标：一年后领先一整年

## 一、总原则

1. **GPA 永远第一优先级** —— 保研、考研复试、奖学金全都看它      /我所在的学校没有         
3. **双线推进**：编程线（C → Python）＋ 动手线（开发板 → 无人机）
4. **英语尽早过级** —— 为读英文文档和考研打底
5. **作品集从大一开始积累** —— 笔记、代码、项目最后都变成简历

## 二、大一上（2026.10 – 2027.1）

### 🍂 课内主线

| 课程 | 目标 | 说明 |
| --- | --- | --- |
| 高等数学 | 吃透 | 极限、导数、积分是飞控和考研数学的地基 |
| C 语言 | 认真跟 | 没开课就自学（B 站：浙大翁恺 / 郝斌） |
| 大学英语 | 保持习惯 | 为大一下考四级做准备 |
| 其他课程 | ≥ 85 分 | 不留 GPA 短板 |

### 课外（每天 30–60 分钟）

- [x] 注册 GitHub 账号
- [ ] 学会用 Markdown 记笔记（进行中）
- [ ] 看无人机原理、开源飞控（PX4 / ArduPilot）科普视频
- [ ] 打听实验室 / 航模社 / 飞行队，去看一次活动

### ❄️ 寒假（2027.1 – 2027.2）

- C 语言查漏补缺：**指针、结构体、文件操作**必须过关
- Python 基础过一遍
- 可选：入一块 Arduino / STM32 最小系统板（百元内）

---

## 三、大一下（2027.2 – 2027.7）

### 🌱 课内

高数下（多元微积分）、**线性代数**（矩阵是飞控的语言）、大学物理、电路分析

### 英语

- 6 月考 **CET-4**，目标 **500+**，一次过，大二冲六级

### 动手线（本学期核心增量）

STM32 入门标准路线（教程任选：正点原子 / 野火）：

```
点亮 LED → 按键 → 串口通信 → 定时器/PWM → 驱动电机 → 读 IMU 传感器
```

- 小项目练手（三选一）：智能小车 / 自平衡小车 / 简易四轴
- 加入实验室或校航模队，完整参与一架飞机的组装调试

### 🏆 竞赛（春季关注）

- 全国大学生电子设计竞赛（校赛选拔）
- 中国国际飞行器设计挑战赛（CDC）
- 互联网+ / 挑战杯（先跟学长组队打杂学习）

### ☀️ 暑假（2027.7 – 2027.8）

- 组装调试第一架航模 / 穿越机（预算几百元）
- MATLAB / Simulink 入门
- 可选：CAAC 无人机执照（不急，大二大三也行）

---

## 四、贯穿全年的习惯

- 每周固定 **≥ 5 小时** 编程 / 动手时间，写进课表
- 学到的东西**输出**成笔记发出去（博客 / GitHub）
- 每学期末复盘一次：GPA、技能进度、下学期重点

---

## 五、给 INFJ 的三条提醒

> **别囤资料**：每项技能只选一套教程，跟到底，收藏夹 ≠ 学会了
>
> **别横向比较**：这行看作品和动手能力，不看出身
>
> **内耗的时候就动手**：焊块板子、飞次飞机，具体的进展会覆盖抽象的焦虑
